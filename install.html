INSTALLATION GUIDE

Follow the instructions below to install custom calling cards and emblems for Black Ops II Plutonium.

CALLING CARDS

INSTALLING IWI FILES

%localappdata%\Plutonium\storage\t6\images
  1. Download the calling-card ZIP package from Plutonium Vault.
  2. Right-click the downloaded ZIP and select Extract All.
  3. Press Windows Key + R on your keyboard.
  4. Paste this into the Run box: %localappdata%\Plutonium\storage\t6
  5. Open the images folder. Create a folder named images if it does not already exist.
  6. Move the extracted .iwi file into the images folder.
  7. Launch Black Ops II through Plutonium and select the calling card that the custom file replaces.
IMPORTANT

Keep the IWI filename unchanged. The filename tells the game which original calling card should be replaced.

EMBLEMS

INSTALLING EMBLEM FILES

%localappdata%\Plutonium\storage\t6\players
  1. Download the emblem ZIP package from Plutonium Vault.
  2. Extract the downloaded ZIP file.
  3. Press Windows Key + R.
  4. Paste this into the Run box: %localappdata%\Plutonium\storage\t6\players
  5. Move the extracted .emblem file into the players folder.
  6. Allow Windows to replace an existing file only when you are happy to overwrite that emblem slot.
  7. Launch multiplayer and open the Emblem Editor to view it.
BACK UP YOUR EMBLEMS

Copy your existing .emblem files somewhere safe before replacing them.

TROUBLESHOOTING

COMMON FIXES

THE CALLING CARD DID NOT CHANGE

Confirm that the IWI file is inside Plutonium\storage\t6\images and that its filename was not changed.

THE EMBLEM DOES NOT APPEAR

Confirm that the extracted .emblem file is directly inside the players folder and not still inside another folder.

THE IMAGES FOLDER IS MISSING

Create a new folder inside storage\t6 and name it exactly images.

THE DOWNLOAD CONTAINS A STRANGE FILENAME

That is normal. Do not rename the IWI or emblem file because the game may require its original filename.
