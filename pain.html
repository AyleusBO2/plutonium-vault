HOW TO INSTALL

  1. Download the Pain calling-card package.
  2. Extract the downloaded ZIP file.
  3. Open your Black Ops II Plutonium T6 game folder.
  4. Place the supplied IWI file in the correct images folder.
  5. Launch Plutonium and select the replaced calling card in-game.

Keep a backup of the original IWI file before replacing it.
