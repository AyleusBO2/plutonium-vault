HOW TO INSTALL

  1. Download the Attack On Titan calling-card package.
  2. Extract the downloaded ZIP file.
  3. Open your Black Ops II Plutonium T6 storage folder.
  4. Move the supplied IWI file into the correct images folder.
  5. Launch Plutonium and select the calling card that the custom file replaces.
